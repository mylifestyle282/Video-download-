# VideoDrop — Video Downloader UI

একটি responsive, Bengali-friendly static video downloader website। GitHub Pages-এ হোস্ট করার জন্য তৈরি।

## কী করতে পারে
- সরাসরি `.mp4`, `.webm`, `.mov`, `.m4v`, `.ogv`, `.avi`, `.mkv` URL গ্রহণ করে
- মোবাইল ও ডেস্কটপের জন্য responsive UI
- URL validation ও status message

## সীমাবদ্ধতা
GitHub Pages শুধু static HTML/CSS/JS host করে। তাই এই প্রজেক্ট YouTube, Facebook, Instagram বা TikTok-এর পেজ URL থেকে ভিডিও extract করতে পারে না। কিছু সার্ভার cross-origin download বন্ধ রাখতে পারে; সেক্ষেত্রে ব্রাউজারের আচরণ ভিন্ন হতে পারে। কপিরাইট, প্ল্যাটফর্মের শর্ত এবং ডাউনলোডের অনুমতি মেনে চলুন।

## GitHub Pages-এ প্রকাশ করুন
1. GitHub-এ নতুন repository তৈরি করুন, যেমন `videodrop`.
2. এই ফোল্ডারের `index.html`, `style.css`, `script.js`, `README.md` ফাইলগুলো repository-র root-এ upload করুন।
3. Repository → **Settings** → **Pages** খুলুন।
4. **Build and deployment**-এ `Deploy from a branch` নির্বাচন করুন।
5. Branch হিসেবে `main` এবং folder হিসেবে `/(root)` নির্বাচন করে **Save** করুন।
6. কয়েক মিনিট পর Pages section-এ প্রকাশিত সাইটের লিংক দেখা যাবে।
